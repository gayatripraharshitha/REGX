# RegX

RegX is a regime-aware portfolio risk analysis project.

The system analyses daily returns from 30 industry portfolios
and compares traditional covariance estimators with adaptive
risk-estimation methods.

## Core Methods

- Sample Covariance
- EWMA
- Ledoit-Wolf
- Method A: Direct Feature-Based Adaptation
- Method B: Clustering-Guided Adaptation
- PCA
- K-Means Clustering
- Minimum-Variance Portfolio Optimisation
- Walk-Forward Backtesting

## Python Files

1. main.py
2. data.py
3. features.py
4. covariance.py
5. portfolio.py
6. backtest.py
7. evaluation.py

## Run

Install dependencies:

pip install -r requirements.txt

Place the dataset at:

data/raw/30_Industry_Portfolios_Daily.csv

Then run:

python main.py

## Web Dashboard

The React dashboard lives in `dashboard/`. It includes a checked-in analysis
snapshot generated by `export_dashboard.py`, so the website needs no Python
server. From this repository's root in Windows PowerShell:

```powershell
cd dashboard
npm.cmd ci
npm.cmd run dev
```

For Vercel, import this GitHub repository and set **Root Directory** to
`dashboard`, framework to **Vite**, build command to `npm run build`, and output
directory to `dist`. Commit `dashboard/public/data/dashboard.json` as well as the
frontend sources and lockfile. See [dashboard/README.md](dashboard/README.md)
for full run, data refresh, and deployment instructions.
